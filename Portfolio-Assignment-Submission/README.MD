\# Car Insurance System



This project is an ASP.NET MVC web application that simulates a car insurance company system. Users can enter policy information and receive insurance quotes based on business logic calculations. The project also includes an admin panel for managing and reviewing customer quotes.



\### Technologies Used

\- C#

\- ASP.NET MVC

\- Entity Framework

\- SQL Server

\- HTML/CSS
